# PhishGuard — Chrome Extension (Stage 2)

The PhishGuard ML model, running **entirely inside your browser**.
Every link you open is checked *before* the page loads:

- 🚨 **Phishing** → the tab is redirected to a full-page red warning
  (with the reasons) before the fake page can load.
- ⚠️ **Suspicious** → a yellow **!** badge appears on the toolbar icon.
- ✅ **Safe** → nothing happens; you browse normally.

Clicking the toolbar icon shows the current page's verdict, risk score
and reasons, and lets you check any other link by pasting it.

**Privacy:** the model (a compact RandomForest exported to JS) and all
checks run locally. No URL ever leaves your browser, and no server is
needed. Extension model metrics: see [MODEL.md](MODEL.md) — 96.75%
accuracy on the held-out test set, and its verdicts were verified to
match the Python model on a 10-URL real/fake battery.

## Install (unpacked, 1 minute)

1. Download this `extension` folder (or clone the repo).
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode** (top-right).
4. Click **Load unpacked** and select this `extension` folder.
5. Pin the PhishGuard shield from the puzzle-piece menu. Done!

## Try it

- Safe: open `https://www.google.com` — no warning.
- Test warning: try opening
  `http://paypal-secure-login.xyz/verify/account?update=1`
  — PhishGuard should stop it with the red warning page.
  (It's a made-up lookalike domain used in this project's tests.)

## Files

```
manifest.json    MV3 manifest (permissions: tabs, webNavigation, storage)
background.js    Service worker — checks every main-frame navigation
warning.html/js  Full-page interstitial for phishing verdicts
popup.html/js    Toolbar popup: current-page verdict + manual checker
features.js      Same 27 URL features as the Python model
engine.js        Tree-walking inference over the exported forest
model.js         Compact RandomForest (generated by ../export_extension.py)
top_domains.js   Tranco top-100k ranks for the popularity feature
icons/           Shield icons
MODEL.md         This model's own measured test metrics
```

## Note

A detector reduces risk; it is not a guarantee. If you ever bypass the
warning ("Main risk samajhta hu, phir bhi kholo"), that site is allowed
for the rest of the browser session.
